# StoryTeller — iOS App (App A)

The mobile player for interactive CYOA books generated by the Forge.

## Requirements

- iOS 16.0+
- 4 GB+ RAM recommended (3 GB minimum for Game Master)
- ~2 GB free storage (for Game Master model + story files)

## Architecture

- **Swift + SwiftUI** — declarative UI, MVVM pattern
- **llama.cpp C API** — local LLM inference via bridging header
- **AVFoundation** — MIDI playback (AVAudioEngine + AVAudioPlayerNode)
- **ZIPFoundation** — .story ZIP extraction
- **AsyncImage** — lazy image loading from extracted PNGs

## Setup

### 1. Build llama.cpp static library

```bash
cd ios
bash build_llama.sh
```

This clones llama.cpp and builds `libllama.a` (fat binary: arm64 device + simulator).

### 2. Open in Xcode

1. Create a new Xcode project: File → New → Project → iOS → App
   - Product Name: `StoryTeller`
   - Interface: `SwiftUI`
   - Language: `Swift`
   - Minimum Deployment: `iOS 16.0`
2. Add all Swift source files from `StoryTeller/` to the project
3. Add `tmp/ios-llama/lib/libllama.a` to **Link Binary With Libraries**
4. Add `tmp/ios-llama/include/` to **Header Search Paths** in Build Settings
5. Set **Objective-C Bridging Header** to `StoryTeller/BridgingHeader.h`
6. Add `ZIPFoundation` via SPM: `https://github.com/weichsel/ZIPFoundation.git`

### 3. Build & Run

Select your target device (iPhone or simulator) and press ⌘R.

## First Launch

1. App checks for model availability in Documents/models/
2. If missing (first launch), downloads Llama-3.2-3B (~2 GB) from Hugging Face
3. Once downloaded, user can import .story files and start reading

## Features

- **Library**: import .story files via file picker (iOS document browser)
- **Reader**: page-by-page CYOA with images, MIDI music, choice buttons
- **Game Master**: ask questions with context-aware LLM (spoiler-gated)
- **Bookmarks**: save your place across sessions
- **Flag system**: choices affect future options (branching narrative)
