# StoryTeller — Android App (App A)

The mobile player for interactive CYOA books generated by the Forge.

## Requirements

- Android 14+ (API 34)
- 6 GB+ RAM recommended (3 GB minimum for Game Master)
- ~2 GB free storage (for Game Master model + story files)

## Architecture

- **Kotlin + Jetpack Compose** — declarative UI
- **llama.cpp JNI (CMake + NDK)** — local LLM inference
- **Material 3** — dark fantasy theme
- **Navigation Compose** — single-activity navigation
- **OkHttp** — model and SoundFont download

## Build

```bash
cd droid

# Android Studio's JBR provides the JDK (no system Java needed)
export JAVA_HOME='/Applications/Android Studio.app/Contents/jbr/Contents/Home'

./gradlew assembleDebug
# Find APK at: app/build/outputs/apk/debug/app-debug.apk
```

## First Launch

1. App starts, checks for Wi-Fi connection
2. If models not downloaded: prompts user to download (~2 GB) over Wi-Fi
3. Once models are ready: user can import .story files and start reading

## Features

- **Library**: import .story files via file picker or share intent
- **Reader**: page-by-page CYOA with images, MIDI music, choice buttons
- **Game Master**: ask questions about the current scene with context-aware LLM
- **Bookmarks**: save your place across sessions
- **Flag system**: choices affect future options (branching narrative)
